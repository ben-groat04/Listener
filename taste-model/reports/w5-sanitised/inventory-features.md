# Inventory: feature and data preparation (inventory-features)

Start/end times: see TIMING.txt in the scratch folder (start 2026-11-21T18:02:35Z).

## Scope and method
Files read in full: all of predictors/w4-shared-prep/, evalkit/data.py, make_decoys.py, fetch_itunes.py, fetch_previews.py, baselines.py, refs.py, the selection and fold parts of run.py (prepare_folds, keep_label, dev_edges, score_predictor), evalkit/README.md (by keyword search; its lines are very long), the feature/prep code of every predictor folder (build_mert, build_clap, build_desc, build_compact*, build_patches, features.py, feats.py, fetch_lyrics, and the feature/target/PCA/missing-value parts of each predict.py and core.py), plus the sanitised W3/W4 reports (by keyword search, not read end to end). Nothing was run except `pd.date_range` (14 folds confirmed) and greps; no experiments, no held-out numbers read or written.
Counting rules: one row per assumption or chosen number; where one code line holds several numbers they are listed in one row if they share evidence and test status. "Reason found" = a reason, comment, plan statement or report evidence exists for the value (a code comment that merely restates the value counts only if it gives a purpose). "Variation found" = some test or comparison of that value or definition was found (cited); "none found" = nothing in the files and reports read. Model hyperparameters (ridge alpha, GBM settings) appear only where they define the input representation or training rows; the model-side inventory is a different agent's area.
Not covered because not read: reports beyond keyword search, evalkit/metrics.py, selftest.py, bundle.py, ablate.py, describe.py (metrics and bookkeeping, not model inputs), the analysis scripts (analyze_*, taste_drift, artist_proxy, artist_excluded_cv, investigate, audit, diag_flip, calib_randdir), and the model-fitting parts of the predictors.

## Facts observed along the way (not rows)
- Every dev stream has playedMs >= 30 s (W4 research-lead-plan q1; confirmed by devils-advocate: min 30001); skips are absent from the data.
- 14 quarterly folds, TUNE 10, LATE 4 (data.py:19-21). The fold boundaries, spacing, 3-month window and 10/4 split have no stated derivation and no variation in any file read (rows F007-F009).
- The label definition is varied only as reported sensitivity (love_4_2, love_10_4, strong, keep); no model was retrained on a different horizon.
- evalkit/data.py:300,318,333: sampling seeds are the cutoff date as integer.
