## What blocked it
- reddit.com and old.reddit.com: WebFetch refuses the domain.
- Reddit mirrors (lr.vern.cc, lr.eu.psf.lt, cal1.lr.ggtyler.dev): HTTP 503.
- sputnikmusic.com: HTTP 403. head-fi.org: bot check page. last.fm: comments did not load.
- WebFetch returns model-summarised text with a short per-quote limit, so long verbatim passages could not be extracted even from pages that loaded.
- WebSearch returns paraphrased summaries, not verbatim text, so it is not usable as a source of quotes.
